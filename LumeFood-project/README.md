# Projeto LumeFood

## Este projeto usa o LumeFood (site criado pela LumeStack inspirado no ifood para treino e realização de estudos de QA)

## O que há neste projeto?
Neste projeto, fiz um caminho completo de testes em um site, usando:

- Planejamento de testes;
- Criação dos cenários de teste através do Trello;
- Testes manuais documentados através do Google Sheets;
- Bug reports documentados no Google Sheets;
- Automação realizada através do Cypress (ainda em desenvolvimento);
- Edge cases;
- Testes exploratórios;
- Testes de API através de Postman (ainda em desenvolvimento)

## Cobrimento de Testes:
Validação de entrada (registro e login);
Validação da interface de usuário;
Validação da funcionalidade do carrinho de compras;
Validação da funcionalidade de finalizar um pedido;
Testes de API com postman (em desenvolvimento);
